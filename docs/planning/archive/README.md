# Planning Archive

This directory holds retired planning memory: completed milestone snapshots, outdated
drafts, superseded plans, and investigation notes that are no longer active.

It is intentionally kept (rather than implied) so the archive path referenced throughout
the active planning docs always resolves.

When archiving a document, follow the archive policy in
[`../README.md`](../README.md#archive-policy):

1. Move it here.
2. Add a short note at the top explaining why it was archived and what replaced it.
3. Remove it from the active document list in `../README.md`.
4. Keep `../roadmap.md` and `../todo.md` focused on current work only.
